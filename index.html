Habit Tracker

Cómo usar Habit Tracker

  1. Escribe el nombre del hábito. Puedes elegir un emoji y un color; el emoji es opcional.
  2. Pulsa Agregar para guardar el hábito.
  3. Pulsa Marcar hoy o una fecha del mapa para registrar un día completado.
  4. Usa Editar para cambiar un hábito o Eliminar para borrarlo.
  5. Cambia la vista a semanal, mensual o anual para revisar tu progreso.
